# Output Walkthrough: Customer Feedback and Drake Sync Guidance

Use these explanations while reviewing Cranston's output with a customer, especially when they ask how to correct data, resolve client questions, or keep work aligned with Drake.

## Correcting or updating return data

If a value or conclusion needs to change, the customer has two ways to update the return:

- Upload a replacement document when new or corrected source material is available.
- Type an instruction in plain language, the same way they would instruct an employee. Cranston will use that instruction to update the draft accordingly.

Suggested language:

> If something needs to change, you can either upload the replacement document or just tell Cranston what to do in plain English—the way you would tell an employee. It will update the draft based on that instruction.

## Sending “ask client” items

When there are several open questions for the taxpayer, the customer does not need to send one message per item.

- Select multiple “ask client” items together.
- Combine them into one client email.
- Review and edit the email before it is sent.

Suggested language:

> You can check off multiple “ask client” items, put them into one email, and review or edit the message before it goes out.

## Drake two-way sync

- Cranston supports two-way sync with Drake: data can be pushed from Cranston to Drake and pulled from Drake into Cranston.
- If a new document arrives after the return is already in Drake—for example, a missing W-2 or 1095-A—the customer can add it to Cranston and sync the updated information back to Drake without manually re-entering it.

Suggested language:

> Cranston and Drake can stay in sync both ways. If a missing W-2 or 1095-A comes in after the return is already in Drake, add it in Cranston, update the draft, and sync it back rather than manually re-entering the data.

## Important: clarify the current draft's connection to Drake

Be precise about whether the specific return being reviewed is connected to the customer's Drake file.

For Scott's session, the draft prepared in the session is a draft inside Cranston only. It is **not** connected to Scott's existing Drake file and will not affect that existing return.

Suggested language:

> One important clarification: this draft is currently inside Cranston. It is not connected to your existing Drake file, so reviewing or changing it here will not affect that return in Drake.

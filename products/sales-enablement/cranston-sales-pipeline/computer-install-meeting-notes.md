# Computer Install Meeting Notes

## Check for blockers before starting

Confirm the target computer is suitable for installation. Common blockers include:

- Insufficient available storage.
- An old or unsupported computer or operating system.
- Other device, permissions, security, or network issues that must be resolved before installation can proceed.

Identify these early in the meeting so the team can either resolve them or agree on the owner and next step.

## Confirm the tax-software environment

Ask whether the customer has the tax software installed directly on the computer being configured or whether they access it through a cloud/hosting provider.

This determines the installation path and whether coordination with the cloud provider or internal IT team is required.

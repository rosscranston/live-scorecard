## Meeting evidence

Create one dated subsection per verified prospect meeting. Include meeting number, meeting type, Circleback ID, source links, short exact quotes with timestamps when available, commitments, and unresolved fields. Never paste the full transcript.

## Rep coaching

Record only call-specific coaching that matters for the next conversation, including whether to focus on the decision path, set up the demo's processing/null state clearly, and invite a skeptical prospect to try the product. Do not treat coaching language as a prospect fact.

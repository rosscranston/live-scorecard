# Minimum rules

The company-wide default minimum is 250 returns. The only customer-facing minimum values are 100, 150, 200, and 250.

- Store `Company Minimum` as 250.
- Store `Minimum Communicated` only when a Cranston representative explicitly states one of the allowed values to the prospect.
- Never infer a lower minimum from firm size, a pilot, or a proposed sample.
- If different sources conflict, use `Needs confirmation` and retain both excerpts.

`Minimum Response` has four values:

- `Not discussed`: no customer reaction to a return minimum appears in the evidence.
- `Reasonable`: the customer explicitly accepts, agrees with, or treats the stated minimum as workable.
- `Too high`: the customer explicitly says the return minimum is too high or unattainable.
- `Unclear`: a minimum was discussed but the reaction cannot be classified confidently.

Store a short exact excerpt in `Minimum Response Evidence`. A generic objection to per-return price, total price, or another commercial term is not automatically an objection to the return minimum.
